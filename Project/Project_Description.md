## Project Description ##



Senior Design Advisor Connect is a website designed to help students find and communicate with professors for senior design projects. The system addresses the difficulty students face when searching for an available advisor whose expertise matches their project idea.



The intended users are students and professors. Students can view professor profiles, areas of expertise, and the number of available team slots. They can submit project ideas, request meetings through available time slots, and communicate with professors through a chat system. Professors can use a dashboard to review student requests and manage their teams, meetings, and availability. The system can also send notifications and reminders to help students begin searching for an advisor on time.
